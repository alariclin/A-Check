ابزار دوسویه بررسی اعتبار IP: خودآزمایی IP خروجی / استعلام هر IP عمومی. فقط کتابخانه استاندارد پایتون، بدون هیچ وابستگی، آماده استفاده.

## ویژگی‌ها

- **۱۶ منبع داده رایگان**، بدون نیاز به کلید API، رایگان و متن‌باز
- **دو حالت**:
  - `[1]` خودآزمایی — بررسی IP خروجی دستگاه فعلی، شامل تست فعال رفع انسداد استریمینگ، تست کامل DNS، تست ارسال پورت ۲۵، ۶۱ لیست سیاه DNSBL، تست سرعت Cloudflare
  - `[2]` استعلام IP — هر IP عمومی را وارد کنید؛ فقط استعلام غیرفعال اطلاعات عمومی، همراه با شبیه‌سازی در دسترس بودن استریمینگ و پیشنهاد DNS
- **رابط کاربری به ۶ زبان**: 简体中文 / 繁體中文 / English / 日本語 / Русский / فارسی
- **امتیاز ریسک ۰ تا ۱۰۰** + نوار پیشرفت رنگی
- **تشخیص رفع انسداد استریمینگ**: تفکیک رفع انسداد بومی / رفع انسداد DNS
- **تست ارسال پورت ۲۵** + ۶۱ لیست سیاه DNSBL (۲۰ رشته موازی، در چند ثانیه تمام می‌شود)
- **اطلاعات سیستم**: CPU / حافظه / دیسک / مجازی‌سازی + بنچمارک I/O دیسک
- **تست سرعت Cloudflare** (فقط برای مرجع)
- **تست کامل DNS**: ‏DNS سنتی (UDP 53) / DoH / DoT
- **سازگار با سه پلتفرم**: macOS / Windows / Linux

## شروع سریع

```bash
# اجرای تک‌خطی برای VPS / Linux / macOS (نیازمند Python 3.8+‎)
curl -sL https://raw.githubusercontent.com/alariclin/IPCheck/main/ipcheck.py -o ipcheck.py && python3 ipcheck.py

# ویندوز: پس از دانلود روی run.bat دابل‌کلیک کنید، یا
python ipcheck.py
```

بدون هیچ وابستگی第三方 — فقط کتابخانه استاندارد پایتون.

## شرح دو حالت

### [1] خودآزمایی

بررسی IP خروجی دستگاه فعلی:

1. پروفایل غیرفعال IP ‏(ASN / BGP / موقعیت جغرافیایی / نوع IP)
2. اطلاعات تهدید (تجمیع ۱۶ منبع)
3. امتیاز تقلب و ماتریس عوامل ریسک
4. اطلاعات سیستم (CPU / حافظه / دیسک / مجازی‌سازی / I/O دیسک)
5. تست فعال استریمینگ (TikTok / Netflix / Disney+ / YouTube / ChatGPT و غیره، تفکیک بومی / DNS)
6. تست کامل DNS (سنتی / DoH / DoT)
7. تست ارسال پورت ۲۵ + لیست‌های سیاه DNSBL
8. تست سرعت Cloudflare

### [2] استعلام IP

هر IP عمومی را وارد کنید؛ فقط استعلام غیرفعال اطلاعات عمومی:

- پروفایل IP چندمنبعی و مقایسه موقعیت
- اطلاعات تهدید و امتیاز ریسک
- شبیه‌سازی در دسترس بودن استریمینگ (⚠️ تست واقعی اتصال نیست، فقط برای مرجع)
- پیشنهاد DNS بر اساس کشور/منطقه IP و فهرست موارد شناخته‌شده مسدود

## منابع داده (۱۶ منبع رایگان)

| دسته | منابع |
|------|-------|
| پروفایل IP | IPWho.is, IPInfo, DB-IP, ProxyCheck, FreeIPAPI |
| اطلاعات تهدید | Scamalytics, SANS ISC, Urlscan.io, StopForumSpam, Feodo Tracker, SSLBL, Tor Exit Nodes |
| شبکه | RIPEstat ‏(ASN/BGP)، ‏PTR (‏DNS معکوس)، Shodan InternetDB |
| لیست سیاه | DNSBL ‏(۶۱ لیست سیاه عمومی) |

> برای بررسی پیشرفته‌تر می‌توانید کلیدهای API خودتان (VirusTotal / AbuseIPDB / AlienVault OTX / IPQualityScore) را در `~/.check_ip_keys` قرار دهید. کلیدها فقط به‌صورت محلی ذخیره می‌شوند و هرگز آپلود نمی‌شوند.
