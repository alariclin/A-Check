A-Check ابزار دوسویه بررسی اعتبار IP است: خودآزمایی IP خروجی / استعلام هر IP عمومی. فقط کتابخانه استاندارد پایتون، بدون هیچ وابستگی، آماده استفاده.

## ویژگی‌ها

- **۱۷ منبع داده رایگان**، بدون نیاز به کلید API، رایگان و متن‌باز
- **دو حالت**:
  - `[1]` خودآزمایی — بررسی IP خروجی دستگاه فعلی، شامل تست فعال رفع انسداد استریمینگ، تست کامل DNS، تست ارسال پورت ۲۵، ۲۹ لیست سیاه DNSBL، تست سرعت Cloudflare
  - `[2]` استعلام IP — هر IP عمومی را وارد کنید؛ فقط استعلام غیرفعال اطلاعات عمومی، همراه با شبیه‌سازی در دسترس بودن استریمینگ و پیشنهاد DNS
- **رابط کاربری به ۶ زبان**: 简体中文 / 繁體中文 / English / 日本語 / Русский / فارسی
- **امتیاز ریسک ۰ تا ۱۰۰** + نوار پیشرفت رنگی
- **تشخیص رفع انسداد استریمینگ**: تفکیک رفع انسداد بومی / رفع انسداد DNS
- **تست ارسال پورت ۲۵** + ۲۹ لیست سیاه DNSBL (۲۰ رشته موازی، در چند ثانیه تمام می‌شود)
- **اطلاعات سیستم**: CPU / حافظه / دیسک / مجازی‌سازی + بنچمارک I/O دیسک
- **تست سرعت Cloudflare** (فقط برای مرجع)
- **تست کامل DNS**: ‏DNS سنتی (UDP 53) / DoH / DoT
- **سازگار با سه پلتفرم**: macOS / Windows / Linux

## شروع سریع

```bash
# اجرای تک‌خطی برای VPS / Linux / macOS (نیازمند Python 3.8+‎)
curl -sL https://raw.githubusercontent.com/alariclin/A-Check/main/acheck.py -o acheck.py && python3 acheck.py

# Windows PowerShell one-liner (requires Python 3.8+)
irm https://raw.githubusercontent.com/alariclin/A-Check/main/acheck.py -OutFile acheck.py; python acheck.py
```

> **نکات اجرای اول**:
> - **macOS**: اگر Gatekeeper فایل `run.command` را مسدود کرد، راست‌کلیک → باز کردن → باز کردن؛ یا `xattr -d com.apple.quarantine run.command` را اجرا کنید
> - **Windows**: اگر SmartScreen فایل `run.bat` را مسدود کرد، روی "اطلاعات بیشتر" → "اجرا" کلیک کنید؛ یا راست‌کلیک → ویژگی‌ها → "رفع انسداد"
> - **Linux**: در صورت خطای دسترسی، ابتدا `chmod +x run.sh` را اجرا کنید

بدون هیچ وابستگی شخص ثالث — فقط کتابخانه استاندارد پایتون.

## شرح دو حالت

### [1] خودآزمایی

بررسی IP خروجی دستگاه فعلی:

1. پروفایل غیرفعال IP ‏(ASN / BGP / موقعیت جغرافیایی / نوع IP)
2. اطلاعات تهدید (تجمیع ۱۷ منبع)
3. امتیاز تقلب و ماتریس عوامل ریسک
4. اطلاعات سیستم (CPU / حافظه / دیسک / مجازی‌سازی / I/O دیسک)
5. تست فعال استریمینگ (TikTok / Netflix / Disney+ / YouTube / ChatGPT و غیره، تفکیک بومی / DNS)
6. تست کامل DNS (سنتی / DoH / DoT)
7. تست ارسال پورت ۲۵ + لیست‌های سیاه DNSBL
8. تست سرعت Cloudflare

### [2] استعلام IP

هر IP عمومی را وارد کنید؛ فقط استعلام غیرفعال اطلاعات عمومی:

- پروفایل IP چندمنبعی و مقایسه موقعیت
- اطلاعات تهدید و امتیاز ریسک
- شبیه‌سازی در دسترس بودن استریمینگ (⚠️ تست واقعی اتصال نیست، فقط برای مرجع)
- پیشنهاد DNS بر اساس کشور/منطقه IP و فهرست موارد شناخته‌شده مسدود
