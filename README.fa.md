## این ابزار چیست

A-Check یک اسکریپت تک‌فایل پایتون است (`acheck.py`، فقط کتابخانه استاندارد، بدون هیچ وابستگی خارجی) که **اعتبار و پاکی** یک آدرس IP را ارزیابی می‌کند و **کیفیت خروجی** شبکه خودتان را می‌سنجد. اطلاعات ۲۲ منبع داده عمومی را در یک گزارش با راستی‌آزمایی متقابل گرد می‌آورد — همه امتیازها تجمیع چند منبع‌اند و هیچ منبعی به‌تنهایی نتیجه را تعیین نمی‌کند.

## دو حالت

| حالت | کاربرد | رفتار |
|---|---|---|
| **خودآزمایی (فعال)** | بررسی IP خروجی فعلی و شبکه محلی شما | بررسی کامل اعتبار IP خروجی، اطلاعات سیستم/سخت‌افزار، تست واقعی رفع مسدودیت استریم، نشت DNS و پیشنهادها، اتصال پورت ۲۵، تست سرعت چندمنطقه‌ای |
| **استعلام هر IP (غیرفعال)** | پیش از خرید VPS یا اجاره پروکسی، پاکی IP طرف مقابل را بسنجید | فقط APIهای اطلاعاتی عمومی فراخوانی می‌شوند و **هیچ بسته‌ای به IP هدف ارسال نمی‌شود** |

## ساختار گزارش

گزارش کامل در بخش‌های شماره‌دار چاپ می‌شود:

- **[1] اطلاعات پایه** — موقعیت، ISP / سازمان، شماره AS؛ **ویژگی‌های نوع IP** (پرچم‌های چندمنبعی: دیتاسنتر / مسکونی / موبایل / پروکسی / VPN / Tor)؛ **گروه موقعیت جغرافیایی** (با نشان کد کشور در ابتدا: موقعیت، مقایسه موقعیت چند منبع، شناسایی معکوس از مختصات، منطقه زمانی، مختصات، پیوند نقشه)؛ در حالت فعال اطلاعات سیستم محلی نیز افزوده می‌شود
- **[2] عوامل خطر** — پروکسی / VPN / Tor / سرور / فهرست سیاه / سوابق مخرب: شش عامل، هر یک با نواری که سهم منابعی را نشان می‌دهد که IP را پرخطر دانسته‌اند
- **[3] امتیاز کلاهبرداری و ابعاد** — امتیاز کلاهبرداری، رفتار تهدید، اعتبار تاریخی، سازگاری با پلتفرم‌ها و امتیاز ترکیبی؛ در پایان **پاکی** و سطح خطر (هرچه کمتر، پاک‌تر)
- **[4] دسترسی استریم و پلتفرم‌ها** — در خودآزمایی نتیجه **تست واقعی** است؛ در استعلام IP دلخواه، **پیش‌بینی** بر پایه سیگنال‌های اعتبار (با ذکر میزان اطمینان)
- **[5] پیشنهاد سرور DNS** — نزدیک‌ترین حل‌کننده‌ها بر اساس موقعیت IP (حالت غیرفعال)
- **[6] کامل بودن داده و اطمینان** — چند منبع واقعاً پاسخ داده‌اند و آیا منابع هسته حاضرند؛ تا داده ناقص جای قطعیت را نگیرد

حالت فعال بخش‌های بدون شماره نیز دارد — نشت DNS و پیشنهادها، اتصال پورت ۲۵ و جدول سرعت چندمنطقه‌ای — در مجموع ۸ بخش.

## ۱۲ قابلیت منوی اصلی

| # | قابلیت | توضیح |
|---|---|---|
| 1 | خودآزمایی (بررسی کامل خروجی) | اسکن کامل حالت فعال، با جدول سرعت چندمنطقه‌ای در پایان |
| 2 | استعلام هر IP | یک IPv4 یا IPv6 عمومی وارد کنید تا گزارش غیرفعال بگیرید؛ پس از پایان، بازگشت خودکار به منوی اصلی |
| 3 | تست رفع مسدودیت استریم | تست واقعی جداگانه برای ۱۸ پلتفرم |
| 4 | اطلاعات سیستم و تست IO | سیستم / پردازنده / حافظه / دیسک و سرعت خواندن-نوشتن دیسک |
| 5 | تغییر زبان / Language | 简体中文 / 繁體中文 / English / 日本語 / Русский / فارسی |
| 6 | بررسی به‌روزرسانی | مقایسه با تازه‌ترین Release در GitHub |
| 7 | عیب‌یابی پروکسی (SOCKS5) | شش گام: دست‌دهی ← IP خروجی پروکسی ← اعتبار خروجی ← نشت DNS ← تأخیر TCP ← توان عملیاتی از راه پروکسی (سریع‌ترینِ ۵ هاب منطقه‌ای) |
| 8 | تست نشت DNS | مقایسه حل‌کننده سیستمی با حل مستقیم برای تشخیص نشت DNS |
| 9 | تست تأخیر TCP | تأخیر / لرزش / از دست رفتن بسته تا هر host:port ‏(min / avg / max) |
| 10 | توضیح قواعد امتیازدهی | شرح کامل ابعاد امتیاز، کسرها و سطوح |
| 11 | تست سرعت دسته‌ای گره‌ها | چند host:port یا پروکسی SOCKS5 بچسبانید؛ سنجش هم‌زمان تأخیر و دسترس‌پذیری، خروجی رتبه‌بندی‌شده با بهترین گره به رنگ سبز، به‌همراه سرعت دانلود واقعی بهترین پروکسی |
| 12 | تست سرعت شبکه (مناطق) | جدول دانلود ۱۷ گره منطقه‌ای (اوج چنداتصاله) به‌همراه سرعت ارسال/دریافت محلی |

تست واقعی استریم ۱۸ پلتفرم را پوشش می‌دهد: هوش مصنوعی (ChatGPT / Gemini / Claude / Grok / DeepSeek)، ویدیو (TikTok / Disney+ / Netflix / YouTube / Amazon Prime Video / Apple TV+)، اجتماعی و دیگر (Facebook / Instagram / Reddit / X / WhatsApp / Line / GitHub)، با تمایز میان رفع مسدودیت بومی و رفع مسدودیت DNS ‏(Smart DNS).

## شروع سریع

بسته سیستم خود را از [Releases](https://github.com/alariclin/A-Check/releases) بگیرید، از حالت فشرده خارج کنید و اجراکننده را اجرا کنید:

- **macOS**: روی `run.command` دوبار کلیک کنید (یا `bash run.command`)؛ یا بسته mac-app را بگیرید، از حالت فشرده خارج کنید و روی `A-Check.app` دوبار کلیک کنید
- **Windows**: روی `run.bat` دوبار کلیک کنید
- **Linux / VPS**: ‎`bash run.sh`

**اجرای تک‌دستوری** (کپی و جای‌گذاری کنید — نسخهٔ فعلی را دانلود و اجرا می‌کند):

macOS:
```
curl -sL https://github.com/alariclin/A-Check/releases/download/v4.14.1/A-Check-v4.14.1-mac-app.zip -o acheck-app.zip && unzip -qo acheck-app.zip && open A-Check.app
```

Linux / VPS:
```
curl -sL https://github.com/alariclin/A-Check/releases/download/v4.14.1/A-Check-v4.14.1-linux.zip -o acheck.zip && unzip -qo acheck.zip && cd acheck-linux && bash run.sh
```

Windows (PowerShell):
```
Invoke-WebRequest https://github.com/alariclin/A-Check/releases/download/v4.14.1/A-Check-v4.14.1-windows.zip -OutFile acheck.zip; Expand-Archive acheck.zip -Force; cd acheck-win; .\run.bat
```

هر سیستم (تک‌فایل، Python 3.8+ لازم است):
```
curl -sL https://raw.githubusercontent.com/alariclin/A-Check/main/acheck.py -o acheck.py && python3 acheck.py
```

**آینهٔ CDN — برای مناطقی که دسترسی مستقیم به GitHub دشوار است (مانند چین). نسخهٔ تک‌فایل، با امکانات کامل:**
gh-proxy (دسترسی مستقیم از چین):
```
curl -sL https://gh-proxy.com/https://raw.githubusercontent.com/alariclin/A-Check/main/acheck.py -o acheck.py && python3 acheck.py
```
jsDelivr:
```
curl -sL https://cdn.jsdelivr.net/gh/alariclin/A-Check@main/acheck.py -o acheck.py && python3 acheck.py
```
statically (پشتیبان):
```
curl -sL https://cdn.statically.io/gh/alariclin/A-Check/main/acheck.py -o acheck.py && python3 acheck.py
```
یا اسکریپت را مستقیم اجرا کنید (Python 3.8+ لازم است):

```
python3 acheck.py            # منوی تعاملی
python3 acheck.py 8.8.8.8    # استعلام یک IP
```

## خط فرمان

```
python3 acheck.py [IP] [گزینه‌ها]
```

| گزینه | توضیح |
|---|---|
| `IPv4` | استعلام غیرفعال یک IP عمومی |
| `--active` | حالت فعال: خودآزمایی کامل خروجی |
| `--ipv4-only` | همراه `--active`: فقط IPv4 (بدون IPv6) |
| `--ipv6-only` | همراه `--active`: فقط IPv6 |
| `--proxy HOST:PORT` | عیب‌یابی پروکسی (در صورت نیاز `--proxy-user` / `--proxy-pass`) |
| `--batch فهرست` | رتبه‌بندی دسته‌ای گره‌ها (host:port یا پروکسی‌های socks5:// با جداکننده کاما) |
| `--speed` | جدول سرعت چندمنطقه‌ای |
| `--explain` | چاپ قواعد امتیازدهی |
| `--json` | خروجی JSON (قابل ترکیب با IP / --active / --proxy) |
| `--zh / --zh-tw / --en / --ja / --ru / --fa` | زبان خروجی |

## منابع داده

تجمیع چندمنبعی با ذکر هر منبع، از جمله:

- **جغرافیا و مالکیت**: ip-api.com، ipwho.is، ipwhois.app، ipinfo.io، FreeIPAPI، ipapi.is، ip.guide، GeoJS، DB-IP، RIPEstat، جستجوی معکوس PTR/FCrDNS
- **اعتبار و کلاهبرداری**: Scamalytics، proxycheck.io، Shodan InternetDB، GreyNoise، SANS ISC، StopForumSpam، urlscan.io
- **تهدیدها و فهرست‌ها**: Spamhaus DROP، Feodo Tracker، Emerging Threats، فهرست گره‌های خروجی Tor

هر عامل و امتیاز حاصل رأی چند منبع است؛ مثبت کاذب یک منبع به‌تنهایی نتیجه را تعیین نمی‌کند.

## نکات

- استعلام غیرفعال IPv4 و IPv6 عمومی را می‌پذیرد؛ نشانی‌های خصوصی / رزروشده با توضیح رد می‌شوند. گزارش IPv6 در سطح پیشوند/اپراتور است (جغرافیا/ASN/نوع/فهرست مسدودی و سیگنال‌های اعتبار به تفکیک منبع، بدون امتیاز ترکیبی). خودآزمایی دوپشته است: اگر خروجی IPv6 وجود داشته باشد در کنار IPv4 آزمایش می‌شود و اگر دو خروجی در شبکه‌های متفاوت باشند هشدار نشت داده می‌شود
- حالت پیش‌بینی (دسترسی استریم برای یک IP دلخواه) از سیگنال‌های اعتبار استنتاج می‌شود و ممکن است با تست واقعی تفاوت داشته باشد — به اطمینان درج‌شده در گزارش تکیه کنید
- تست‌های سرعت بر مبنای اوج چنداتصاله‌اند و ظرفیت اوج پیوند را نشان می‌دهند، نه سرعت پایدار تک‌اتصال
- پهنای ترمینال ≥ ۶۰ ستون پیشنهاد می‌شود؛ در محیط متنی ساده (لوله / بدون رنگ) خروجی به‌صورت خودکار بدون رنگ می‌شود
- این ابزار برای خودآزمایی و ارزیابی عملیاتی است؛ شرایط استفاده هر منبع داده را رعایت کنید

## اگر سیستم جلوی نخستین اجرا را گرفت

- **macOS**: ‏A-Check.app امضای Apple Developer ندارد، پس نخستین اجرا ممکن است مسدود شود («توسعه‌دهنده ناشناس»). روی `A-Check.app` (یا `run.command`) راست‌کلیک کنید ← «Open» ← در پنجره تأیید دوباره «Open» را بزنید. فقط یک بار لازم است؛ از «System Settings ← Privacy & Security» هم می‌توانید اجازه دهید
- **Windows**: نخستین اجرای `run.bat` ممکن است هشدار SmartScreen بدهد — «More info» و سپس «Run anyway» را بزنید
