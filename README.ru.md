IPCheck — двухрежимный инструмент проверки репутации IP: самодиагностика исходящего IP / запрос любого публичного IP. Только стандартная библиотека Python, ноль зависимостей, работает сразу.

## Возможности

- **15 бесплатных источников данных**, API-ключи не нужны, бесплатно и с открытым кодом
- **Два режима**:
  - `[1]` Самодиагностика — проверка исходящего IP текущего устройства: активные тесты разблокировки стриминга, полные тесты DNS, тест отправки через порт 25, 29 чёрных списков DNSBL, замер скорости Cloudflare
  - `[2]` Запрос IP — введите любой публичный IP для пассивного запроса публичной разведки, с симуляцией доступности стриминга и рекомендациями DNS
- **Интерфейс на 6 языках**: 简体中文 / 繁體中文 / English / 日本語 / Русский / فارسی
- **Оценка риска 0–100** + цветной индикатор
- **Детект разблокировки стриминга**: различает нативную разблокировку и разблокировку через DNS
- **Тест отправки через порт 25** + 29 чёрных списков DNSBL (20 потоков параллельно, готово за секунды)
- **Информация о системе**: CPU / память / диск / виртуализация + бенчмарк дискового I/O
- **Замер скорости Cloudflare** (только для справки)
- **Полные тесты DNS**: классический DNS (UDP 53) / DoH / DoT
- **Кроссплатформенность**: macOS / Windows / Linux

## Быстрый старт

```bash
# Одна команда для VPS / Linux / macOS (нужен Python 3.8+)
curl -sL https://raw.githubusercontent.com/alariclin/IPCheck/main/ipcheck.py -o ipcheck.py && python3 ipcheck.py

# Windows PowerShell one-liner (requires Python 3.8+)
irm https://raw.githubusercontent.com/alariclin/IPCheck/main/ipcheck.py -OutFile ipcheck.py; python ipcheck.py
```

> **При первом запуске**:
> - **macOS**: если Gatekeeper блокирует `run.command` ("не может быть проверен"), щёлкните правой кнопкой → Открыть → Открыть; или выполните `xattr -d com.apple.quarantine run.command`
> - **Windows**: если SmartScreen блокирует `run.bat` ("защитил ваш компьютер"), нажмите "Подробнее" → "Выполнить в любом случае"; или правый клик → Свойства → "Разблокировать"
> - **Linux**: при ошибке доступа сначала выполните `chmod +x run.sh`

Никаких сторонних зависимостей — только стандартная библиотека Python.

## Режимы

### [1] Самодиагностика

Проверка исходящего IP текущего устройства:

1. Пассивный профиль IP (ASN / BGP / геолокация / тип IP)
2. Threat intelligence (агрегация 15 источников)
3. Оценка мошенничества и матрица факторов риска
4. Информация о системе (CPU / память / диск / виртуализация / дисковый I/O)
5. Активные тесты стриминга (TikTok / Netflix / Disney+ / YouTube / ChatGPT и др., нативная vs DNS-разблокировка)
6. Полные тесты DNS (классический / DoH / DoT)
7. Тест отправки через порт 25 + чёрные списки DNSBL
8. Замер скорости Cloudflare

### [2] Запрос IP

Введите любой публичный IP для пассивного запроса публичной разведки:

- Мультиисточниковый профиль IP и сравнение геолокации
- Threat intelligence и оценка риска
- Симуляция доступности стриминга (⚠️ НЕ реальные тесты соединения, только для справки)
- Рекомендации DNS по стране/региону IP и список заведомо недоступных

## Источники данных (15 бесплатных)
