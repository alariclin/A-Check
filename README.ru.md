## Что это

A-Check — однофайловый Python-скрипт (`acheck.py`, только стандартная библиотека, ноль внешних зависимостей) для оценки **репутации и чистоты** IP-адреса и проверки **качества исходящего соединения** вашей сети. Он объединяет данные 33 публичных источников в один перекрёстно проверенный отчёт: все оценки являются агрегатом нескольких источников, и ни один источник не определяет результат в одиночку.

## Два режима

| Режим | Назначение | Поведение |
|---|---|---|
| **Самопроверка (активный)** | Проверить текущий исходящий IP и локальную сеть | Полная репутация исходящего IP, информация о системе/железе, фактические тесты разблокировки стриминга, утечка DNS и рекомендации, доступность порта 25, тест скорости по регионам |
| **Запрос любого IP (пассивный)** | Проверить IP перед покупкой VPS или арендой прокси | Только запросы к публичным API — **пакеты на целевой IP не отправляются** |

## Структура отчёта

Пассивный отчёт выводится пронумерованными разделами:

- **[1] Базовая информация** — местоположение, ISP / организация, номер AS; **атрибуты типа IP** (дата-центр / резидентный / мобильный / прокси / VPN / Tor по данным нескольких источников); **группа геолокации** (в начале — бейдж с кодом страны: местоположение, часовой пояс, координаты, ссылка на карту, обратное определение по координатам, сравнение позиций из разных источников — каждый отличный вывод отдельной строкой с заголовком); в активном режиме добавляется информация о локальной системе
- **[2] Факторы риска** — прокси / VPN / Tor / сервер / блоклист / вредоносные записи: шесть факторов, для каждого — полоса с долей источников, пометивших IP как рискованный
- **[3] Мошенничество и оценки по измерениям** — оценка мошенничества, угрожающее поведение, историческая репутация, совместимость с платформами и сводная оценка; в конце — **чистота** и уровень риска (чем ниже, тем чище)
- **[4] Стриминг и доступность платформ** — в самопроверке это **фактические** результаты тестов; при запросе чужого IP — **прогноз** по сигналам репутации (с указанной достоверностью)
- **[5] Рекомендации DNS** — ближайшие резолверы по местоположению IP (пассивный режим)
- **[6] Полнота данных и достоверность** — сколько источников реально ответило и на месте ли ключевые, чтобы неполные данные не выдавались за определённость

В режиме самопроверки разделы также пронумерованы. IPv4 — это **[1]–[8]**: фактический стриминг [4], полный тест DNS (26 обычных / 15 DoH / 12 DoT, ранжирование по задержке и отметка самого быстрого) и рекомендации [5], тест скорости [6], проверки порта 25 и DNSBL [7], полнота [8]. При наличии выходного IPv6 далее идут вердикт о двухстечности и полный стек IPv6 **[9]–[17]** — отчёт IPv6 с сигналами репутации по источникам, тест IPv6 DNS (обычный / DoH / DoT, с отметкой самого быстрого), стриминг IPv6 и скорость IPv6, — а два выхода сравниваются на предмет утечки.

## 12 функций главного меню

| # | Функция | Описание |
|---|---|---|
| 1 | Самопроверка (полная проверка) | Полное сканирование в активном режиме; при наличии выхода IPv6 — двухстековая проверка |
| 2 | Запрос любого IP | Введите публичный IPv4 или IPv6 для пассивного отчёта; после завершения — автоматический возврат в главное меню |
| 3 | Проверка стриминга | Отдельный фактический тест разблокировки 18 платформ |
| 4 | Система и тест IO | Система / CPU / память / диск и скорость чтения-записи диска |
| 5 | Язык / Language | 简体中文 / 繁體中文 / English / 日本語 / Русский / فارسی |
| 6 | Проверить обновления | Сравнение с последним Release на GitHub |
| 7 | Диагностика прокси (SOCKS5) | Шесть шагов: рукопожатие → исходящий IP прокси → его репутация → утечка DNS → задержка TCP → пропускная способность через прокси (самый быстрый из 5 региональных хабов) |
| 8 | Утечка DNS | Сравнение системного резолвера и прямого разрешения для выявления утечки DNS |
| 9 | Тест задержки TCP | Задержка / джиттер / потери пакетов до любого host:port (min / avg / max) |
| 10 | Правила оценки | Полное объяснение измерений оценки, вычетов и уровней |
| 11 | Пакетный тест узлов | Вставьте несколько host:port или SOCKS5-прокси; параллельная проверка задержки и доступности, рейтинг с лучшим узлом зелёным, плюс фактическая скорость загрузки лучшего прокси |
| 12 | Тест скорости (регионы) | Таблица загрузки для 28 региональных узлов (пик по нескольким соединениям) и скорости вашего канала |

Фактические тесты стриминга охватывают 18 платформ: ИИ (ChatGPT / Gemini / Claude / Grok / DeepSeek), видео (TikTok / Disney+ / Netflix / YouTube / Amazon Prime Video / Apple TV+), соцсети и прочее (Facebook / Instagram / Reddit / X / WhatsApp / Line / GitHub), с различением нативной разблокировки и разблокировки через DNS (Smart DNS).

## Быстрый старт

Скачайте пакет для вашей системы из [Releases](https://github.com/alariclin/A-Check/releases), распакуйте и запустите:

- **macOS**: двойной щелчок по `run.command` (или `bash run.command`); либо скачайте пакет mac-app, распакуйте и дважды щёлкните `A-Check.app`
- **Windows**: двойной щелчок по `run.bat`
- **Linux / VPS**: `bash run.sh`

**Запуск одной командой** (скопируйте и вставьте — скачает текущий релиз и запустит):

macOS:
```
curl -sL https://github.com/alariclin/A-Check/releases/download/v4.14.24/A-Check-v4.14.24-mac-app.zip -o acheck-app.zip && python3 -c "import zipfile; zipfile.ZipFile('acheck-app.zip').extractall()" && open A-Check.app
```

Linux / VPS:
```
curl -sL https://github.com/alariclin/A-Check/releases/download/v4.14.24/A-Check-v4.14.24-linux.zip -o acheck.zip && python3 -c "import zipfile; zipfile.ZipFile('acheck.zip').extractall()" && cd acheck-linux && bash run.sh
```

Windows (PowerShell 5.1+):
```
Invoke-WebRequest https://github.com/alariclin/A-Check/releases/download/v4.14.24/A-Check-v4.14.24-windows.zip -OutFile acheck.zip; Expand-Archive acheck.zip -Force; cd acheck-win; .\run.bat
```

Любая система (один файл, нужен Python 3.8+):
```
curl -sL https://raw.githubusercontent.com/alariclin/A-Check/v4.14.24/acheck.py -o acheck.py && python3 acheck.py
```

**Зеркало CDN — для регионов, где GitHub труднодоступен (например, материковый Китай). Один файл, полный функционал:**
gh-proxy (прямой доступ из Китая):
```
curl -sL https://gh-proxy.com/https://raw.githubusercontent.com/alariclin/A-Check/v4.14.24/acheck.py -o acheck.py && python3 acheck.py
```
jsDelivr:
```
curl -sL https://cdn.jsdelivr.net/gh/alariclin/A-Check@v4.14.24/acheck.py -o acheck.py && python3 acheck.py
```
Или запустите скрипт напрямую (нужен Python 3.8+):

```
python3 acheck.py            # интерактивное меню
python3 acheck.py 8.8.8.8    # запрос одного IP
```

## Командная строка

```
python3 acheck.py [IP] [опции]
```

| Опция | Описание |
|---|---|
| `IP` | Пассивный запрос публичного IP (IPv4 или IPv6) |
| `--active` | Активный режим: полная самопроверка исходящего IP |
| `--ipv4-only` | С `--active`: только IPv4 (без IPv6) |
| `--ipv6-only` | С `--active`: только IPv6 |
| `--proxy HOST:PORT` | Диагностика прокси (при необходимости `--proxy-user` / `--proxy-pass`) |
| `--batch СПИСОК` | Пакетный рейтинг узлов (host:port или socks5:// через запятую) |
| `--speed` | Таблица скорости по регионам |
| `--no-speed` | С `--active`: пропустить тест скорости (интерактивная самопроверка по умолчанию сначала спрашивает) |
| `--explain` | Вывести правила оценки |
| `--json` | Вывод в JSON (сочетается с IP / --active / --proxy) |
| `--zh / --zh-tw / --en / --ja / --ru / --fa` | Язык вывода |

Агрегация многих источников с указанием каждого:

- **Геолокация и принадлежность**: ip-api.com, ipwho.is, ipwhois.app, ipinfo.io, FreeIPAPI, ipapi.is, ip.guide, GeoJS, DB-IP, RIPEstat, iplocate.io, ipquery.io, ipapi.co, 2ip.io, HackerTarget, country.is, RDAP, обратный PTR/FCrDNS
- **Репутация и мошенничество**: Scamalytics, proxycheck.io, Shodan InternetDB, GreyNoise, SANS ISC, StopForumSpam, urlscan.io, AlienVault OTX, blocklist.de
- **Угрозы и списки**: Spamhaus DROP, Feodo Tracker, Emerging Threats, список выходных узлов Tor, IPsum, X4BNet VPN ranges

Каждый фактор и оценка — результат голосования нескольких источников; ложное срабатывание одного источника не решает исход в одиночку.

## Примечания

- Пассивный запрос принимает публичные IPv4 и IPv6; частные и зарезервированные адреса отклоняются с объяснением. Отчёт по IPv6 — на уровне префикса/оператора (гео/ASN/тип/блок-листы, сигналы репутации по источникам и балл по той же формуле — оценка уровня префикса). Самопроверка — двойной стек: при наличии выхода IPv6 он тестируется вместе с IPv4, с предупреждением об утечке, если выходы в разных сетях
- Режим прогноза (доступность стриминга для чужого IP) выводится из сигналов репутации и может отличаться от фактических тестов — ориентируйтесь на достоверность, указанную в отчёте
- Тесты скорости используют пиковую пропускную способность по нескольким соединениям — это пиковая способность канала, а не устойчивая скорость одного соединения
- Тесты скорости создают реальный трафик загрузки: интерактивная самопроверка сначала запрашивает подтверждение, каждый узел ограничен 200 MB, фактический трафик выводится по стекам, а `--no-speed` полностью пропускает тест
- Рекомендуется ширина терминала ≥ 60 колонок; в текстовой среде (пайпы / без цвета) вывод автоматически становится бесцветным
- Инструмент предназначен для самопроверки и эксплуатационной оценки; соблюдайте условия использования источников данных

## Если система блокирует первый запуск

- **macOS**: у A-Check.app нет подписи Apple Developer, поэтому первый запуск может быть заблокирован («разработчик не установлен»). Разрешите в «Системные настройки → Конфиденциальность и безопасность» (требуется только один раз). На старых версиях macOS (до Sequoia) можно также щёлкнуть правой кнопкой по `A-Check.app` (или `run.command`) → «Открыть» → подтвердить ещё раз кнопкой «Открыть».
- **Windows**: при первом запуске `run.bat` может появиться SmartScreen — нажмите «Подробнее» → «Выполнить в любом случае»
